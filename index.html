Upload an Excel file to visualize coverage % and user counts across Indian states

📋 How to use
  • Prepare an Excel (.xlsx / .xls) file with a State column, a count column (e.g. Count, Users), and a % column (e.g. %, % Covered, Coverage)
  • Map colours are driven by the % (0–100) column using 4 brackets: 0–20 · 21–50 · 51–80 · 80–100
  • User count is still shown below each state name on the map
  • Upload the file by dragging it below or clicking to browse
  • Hover over states to see details — download the map as SVG or high-res PNG
